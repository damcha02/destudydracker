# Study Tracker

Study Tracker is a desktop app for planning study work, tracking focus sessions, monitoring course progress, and exporting daily notes to an Obsidian vault.

The app is built with React, Vite, and Tauri.

## Run

```bash
cd desktop
npm install
npm run tauri:dev
```

## Build

```bash
cd desktop
npm run tauri:build
```
